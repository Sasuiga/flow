flow v0.1.2（M1.5：Avalon 风格 UI + 客户/项目/任务三级管理）快速上手
====================================================================

1. 双击 start.bat —— 浏览器会自动打开 http://localhost:4120
   （会有一个最小化的命令行窗口在跑服务，用它期间别关那个窗口）
   升级注意：若之前在跑旧版 flow，先关掉旧的最小化窗口；数据（data 文件夹）
   会自动迁移，不用删除。

2. 设置页（与 0.1.1 相同）：LLM / OCR 端点、模型名、自定义请求头。
   若上一版已配好且复用旧 data 文件夹，设置会自动保留。

3. 新的主流程（对齐 Avalon 的项目管理方式）：
   首页「新建客户」→ 填名称（如 xx股份有限公司）→ 选位置：
     · 新建目录（默认）：用目录选择器浏览/新建文件夹，flow 自动创建目录并写标记
     · 使用已有目录：直接登记现成文件夹
   客户下「新建融资项目」（如 IPO / 再融资 / 可转债）→ 项目下「新建报告期任务」
   （如 2024 年度募资流水分析）。
   把银行流水 PDF 放进任务目录 → 任务页点「重新扫描」即可登记。

   目录不用再手敲路径了：所有「选择文件夹」都是 Avalon 式目录浏览器
   （可浏览子目录 / 进上级 / 新建文件夹）。
   目录选择器默认从当前用户主目录打开；要改根目录，给 start.bat 加一行
   set FLOW_DOC_ROOT=C:\你的目录（在 start 命令之前）。

4. 每级目录都有 .flow 标记文件（client.json / project.json / task.json），
   与 Avalon 的 .avalon/project.md 同一思路：目录是真身，数据库只是索引。
   以后把整个客户文件夹拷到别的电脑，可以重新登记找回。

本版本（M1.5）已包含：Avalon 风格界面、客户/项目/任务三级创建与浏览、
目录选择器、任务目录 PDF 登记与重新扫描。
交易解析（把 PDF 变成交易表）下个版本（M2）解锁。

停止服务：关闭那个最小化的 flow 窗口即可。
数据位置：data 文件夹（SQLite 数据库），备份 = 复制整个 data 文件夹。

常见问题
--------
- 页面没打开：直接浏览器访问 http://localhost:4120；端口被占用就关掉旧实例
- LLM「连接失败」：确认端点从这台电脑可达、请求头正确
- 「模型不在列表」：平台切换过模型，按提示里的可用模型名更新后保存
- 目录选择器显示「目录不存在或已被删除」：该路径确实不在了，点「上级」或重输路径
- 旧版建过「项目」的，这次升级后会自动挂到一个「遗留客户」下，可在新界面里整理
