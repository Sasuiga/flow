flow v0.2.0（M2：流水 PDF 自动解析 → 结构化交易表）快速上手
====================================================================

1. 双击 start.bat —— 服务起来后浏览器会自动打开 http://localhost:4120
   （会有一个最小化的命令行窗口在跑服务，用它期间别关那个窗口）
   若窗口停住并打印 flow.log：服务没听上 4120，按日志排查（常见是端口被占用）。
   升级注意：若之前在跑旧版 flow，先关掉旧的最小化窗口；数据（data 文件夹）
   会自动迁移，不用删除。

2. 设置页：LLM / OCR 端点、模型名、自定义请求头（与 0.1.2 相同）。
   解析靠 LLM，先用设置页「测试 LLM」确认端点可达再干活。

3. 主流程（0.1.2 已会的：建客户 → 建融资项目 → 建报告期任务）：
   把银行流水 PDF 放进【任务目录】——本版本起【自动识别】：
   · 新 PDF 放进去后几秒内自动登记并开始解析（不用点任何按钮）；
   · 任务页状态 chip 会从「待解析」→「解析中…」→「已完成 / 待复核」；
   · 顶部「查看交易」进交易浏览器看结果；点某份文件行只看该文件的交易。

4. 交易浏览器（顶栏「交易」标签，或任务页「查看交易」）：
   · 跨任务全量交易表：日期/金额/余额/摘要/对手方/银行账户/文件/状态；
   · 过滤：任务/银行/账户/日期区间/对手方/状态/分类 + 流入流出合计；
   · 点行可展开：原始页内那一行的布局文本 + 第几页第几行 + 复核原因；
   · 顶栏「当前任务」切换器：选任务后「交易」页默认只看该任务。

5. 任务页新按钮：
   · 「全部解析」：把所有待解析/出错的 PDF 重新入队；
   · 文件行 ⋯ 菜单：开始解析 / 重新解析 / 查看交易 / 删除登记；
   · 「待复核」= 解析有拿不准的行（低置信/日期/余额对不上），下一版（M3）
     有专门的修正队列逐行改；「错误」多为扫描件（M3 接 OCR 后自动解析）。

本版本（M2）已包含：任务目录自动监听与解析队列、PDF 文字层提取 + 行重建、
LLM 结构化（银行/账号/期间自动识别，逐笔交易入库）、余额连续性初检与
复核标记、交易浏览器（过滤/排序/分页/原始文本下钻）、顶栏当前任务切换器。
扫描件 OCR、修正队列、逐笔分类、规则预警、Excel/MD 导出在 M3~M6 陆续交付。

停止服务：关闭那个最小化的 flow 窗口即可。
数据位置：data 文件夹（SQLite 数据库），备份 = 复制整个 data 文件夹。

常见问题
--------
- 页面没打开：直接浏览器访问 http://localhost:4120；端口被占用就关掉旧实例
- PDF 一直「解析中」：LLM 慢属正常（Jetson 27B 一批几十秒~1~2 分钟）；
  超过 10 分钟没动，看设置页 LLM 测试是否通、任务页「错误」提示
- 「文字层缺失（疑似扫描件）」：该 PDF 是扫描图片，M3 起走 OCR 通道自动解析
- LLM「连接失败」：确认端点从这台电脑可达、请求头正确
- 「模型不在列表」：平台切换过模型，按提示里的可用模型名更新后保存
